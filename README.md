
# Relatório Power BI – Experiência do Usuário

Este projeto atualiza um relatório financeiro no Power BI com foco na experiência do usuário (UX), seguindo:
- Posicionamento, contraste, proporção áurea e segmentação dos dados
- Navegabilidade por botões e menus
- Três páginas: Visão Geral, Detalhe Produto/Segmento e Exploração & Menus

## Conteúdo
- `Relatorio_PowerBI_Experiencia_Usuario_Lavinia.docx`: guia completo de implementação
- `imagens/`: (opcional) screenshots do layout e tema roxo

## Como usar
1. Abra o documento `.docx` para seguir o roteiro.
2. Replique o layout no Power BI (.pbix).
3. Configure botões com ações de navegação (Home, Próximo, Voltar).
